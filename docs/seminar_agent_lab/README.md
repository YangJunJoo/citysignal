# AI-Agent Lab: Extract and Validate Traffic Signal Events

A 60-minute, prompt-based seminar lab. Participants ask an AI agent to execute the existing ATSPM extractor, inspect its outputs, and support an interpretation with source evidence. No participant coding is required.

## Materials

- [Participant handout](participant_handout.md): agenda, background, and prompts to copy into the agent.
- [Participant worksheet](participant_worksheet.md): observations, evidence, and final interpretation.
- [Facilitator guide](facilitator_guide.md): preparation, example configuration, expected findings, and assessment.

## What the lab produces

Each participant produces a newly extracted vehicle phase-state table, a ten-minute timeline, one raw-event trace supporting an interval, and a short evidence-based report. Unmapped phase observations remain diagnostic records.

Cycle-based measures are outside this lab's available outputs because the supplied examples have no verified controller ring/barrier plan. The lane inventory also lacks confirmed historical effective dates. These limitations must appear in the interpretation.

The examples were checked against this project's saved results on November 10, 2026. The facilitator must rehearse them using the current code and inputs before the seminar.
