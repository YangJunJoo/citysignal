# Historical extraction comparisons

These `.py.txt` files preserve the original manual comparison programs before
the extractor package was consolidated. They are historical source text, not
supported commands. Some contain imports and paths belonging to the old local
environment, and some wrote into production output directories.

Use `scripts/compare_reference_outputs.py` to compare saved reference and
candidate output trees without changing either tree. The old command paths
remain available as compatibility entry points to this read-only tool.
